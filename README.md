# Java League

Одностраничный учебный трекер для двух друзей, изучающих Java с нуля.

## Запуск
Просто откройте `index.html` в браузере.

## Возможности
- Roadmap на 45 недель
- 11 этапов обучения
- недельные мини-проекты
- дневная система 30/60/30 минут
- таймер 2 часа
- шкала понимания 0–5
- Java League XP
- локальное сохранение прогресса через localStorage
- адаптивный дизайн для телефона

Данные хранятся только в браузере пользователя.
